# MeshGenerator

`MeshGenerator.py` automates a DFN-to-TOUGH meshing workflow for fractured porous media simulations. It prepares DFN and matrix meshes, runs external meshing/conversion tools, and assembles TOUGH-style `MESH` and `INCON` files.

The script is designed for file-based research workflows where upstream tools exchange intermediate files such as `InputResult.txt`, `InputResult.poly`, `matrix.uge`, and `dfn.uge`.

## What the Script Does

`MeshGenerator.py` can run the full preprocessing pipeline:

1. Run `DFNsMeshGenerator3D.bat` to generate DFN surface meshes.
2. Trim DFN nodes/cells to a target bounding box.
3. Clean the TetGen `.poly` boundary file.
4. Run TetGen under WSL to generate the matrix mesh.
5. Convert TetGen output into the formats expected by LaGriT.
6. Run LaGriT conversions for DFN and matrix meshes.
7. Assemble TOUGH `MESH`, `MESH_inactive`, and `INCON` files from `matrix.uge` and `dfn.uge`.

It can also skip the earlier stages and rebuild only `MESH` and `INCON` from existing UGE files.

## Requirements

- Python 3.10+
- `numpy`
- `meshio`
- Windows with WSL available if you want to run the TetGen and LaGriT stages from this script
- Local access to the external executables and input files expected by the workflow

Install the Python dependencies with:

```bash
pip install numpy meshio
```

## External Software Used

There are five open-source meshing code or software used in the mesh generation scripts:

- toughio: https://github.com/keurfonluu/toughio
- TetGen: https://wias-berlin.de/software/index.jsp?id=TetGen&lang=1
- LaGriT: https://lagrit.lanl.gov/
- DFNsMeshGenerator3D: https://github.com/wywy941/DFNsMeshGenerator3D
- dfnWorks: https://dfnworks.lanl.gov/

The source code of TOUGHREACT can be purchased from https://tough.lbl.gov/software/toughreact_v4-13-omp/.

The TOUGHREACT input files of the case are also included in GitHub repository.

## Usage

Show the command-line interface:

```bash
python MeshGenerator.py --help
```

Run the complete pipeline in the current directory:

```bash
python MeshGenerator.py --stage pipeline
```

Only rebuild TOUGH `MESH` and `INCON` from existing `matrix.uge` and `dfn.uge`:

```bash
python MeshGenerator.py --stage tough
```

Run with explicit domain bounds:

```bash
python MeshGenerator.py ^
  --workdir . ^
  --x-min 5 --x-max 105 ^
  --y-min 5 --y-max 105 ^
  --z-min 5 --z-max 305 ^
  --aperture 1.0e-4 ^
  --code TOUGH2
```

## Main Command-Line Options

- `--workdir`: working directory containing inputs and executables
- `--stage`: choose `pipeline` or `tough`
- `--x-min`, `--x-max`, `--y-min`, `--y-max`, `--z-min`, `--z-max`: trimming bounds
- `--aperture`: fracture aperture used when building TOUGH files
- `--code`: simulator family identifier, default is `TOUGH2`
- `--dfn-material-id`: keep only DFN cells with material IDs less than or equal to this value
- `--log-level`: logging verbosity

## Notes

- The TetGen and LaGriT stages are executed through WSL from Python.
- The workflow is strongly coupled to the file names used in this repository.
- The script preserves backward-compatible helper functions, but the CLI is the preferred public interface.
- Review the default bounds and aperture values before using the script on a different case.
